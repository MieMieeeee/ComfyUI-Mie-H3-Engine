## 核实过的核心契约（M0 第一、二项）

- `AssetStoryboardEnhancer.__call__(concept, shot_count, *, mode="script", ...)`：
  `concept` 是**第一个位置参数**，script 模式下原样成为 `asset_header.source_script`。
  未知关键字进 `**_unused` 被静默吞掉——`source_script=` 关键字传参无效。已用入口测试 + 受控负对照锁死。
- `parse_roles(count, settings)`：1..8 角色；每行 `角色N：名字 | 状态 | 位置 | 声音`；
  状态 画面内/画外/稍后入场；位置 左/右/中/无；名字 ≤40、不得含 `| ， 、`（会拆列）；行必须覆盖全部编号。
- `parse_script(script, roles, language)`：全文 ≤30000、事件 1..200、单条 ≤2000；
  行格式 `别名 类型 [zh|en]：文本`；别名含 role id/角色N/Character N/显示名（别名冲突报错）；
  语言标记必须放在类型之后、冒号之前（放冒号后会被当成正文）；`_text` 做首尾空白规范化并拒绝 `<d>` 标签。
- `shot_count`：0..20 且 ≤ 事件数（script 模式生成前 probe 即拒绝）。
- script 模式锁定 header（caller-owned，逐字段全等校验）：name、language、roles、camera、look、
  setting、constraints、target_duration_seconds、continuation_overlap_frames、source_script、
  audio_mode（非默认时）、character_designs、scene、light（非 follow_image 时）、light_text。
- **`validate_v2` 已强制 shots 内事件与 `parse_script(source_script)` 结果逐字段全等**
  （含顺序、数量，第一条不符会点名）。因此"模型改台词/漏事件/重复/换序"在核心层即被拒；
  webapp 适配层不重复做生成后比对，改由测试 `test_a_model_that_rewrites_a_line_is_rejected` 锁定。
- `validate_v2` 默认全开 timing/execution：`allocate_frames` 重算并覆盖 shots 时长；
  execution 镜像须英文、voices 映射全部角色、directions 覆盖全部非台词事件且以 "Character N" 开头。

## M0 交付内容

`webapp/services/autodraft.py`：
- `_role_settings_line` / `_event_line`：结构化角色/事件 → 共享解析器的单行格式
  （事件行用 `character_N` id 而非显示名；语言标记仅在与全局语言不同时写）。
- `_round_trip`：序列化 → `parse_roles`/`parse_script` → 与确认事件逐条比对
  （顺序、角色、类型、文字（仅首尾空白规范化）、语言），任何走样在调用模型前拒绝。
- `storyboard_script(roles, events, ...)`:确认稿进第一个位置参数；显式传递全部 header 参数
  （character_count/settings、camera 三项、look/setting/scene/constraints/light/light_text、
  name/language/duration/audio_mode/critic）。

`webapp/flask_app.py` `/api/scripts/auto`：
- mode 分发 concept/revise/script；显式未知 mode → 400 字段错误；缺省仍为 concept（兼容）。

`webapp_tests/test_storyboard_intake.py`（8 项，stub 为"回声"连接器——用生成器实际发出的
payload 组装合法回复，参数没传到就不可能回对）：
- 确认文本进第一个位置参数、header 全字段到达（**计划 §10 三条关键负对照之一**）；
- 未知 mode 拒绝；事件往返逐字段一致；内部换行/角色名含分隔符/分镜数超事件数在调用前拒绝且零模型调用；
- 改台词的模型回复被拒并点名事件；生成后资产库无新增。

受控负对照：临时把调用改为 `concept=""` + `source_script=`（关键字）后 5 项测试转红，恢复后全绿。
