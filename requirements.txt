# The engine's dependencies.
#
# ComfyUI supplies torch, numpy, Pillow, aiohttp, av, psutil, safetensors
# and requests itself, so none of those are listed here.
#
# What it does not supply:
#
#   comfyui-mie-craft - the zero-LLM plan assembler and the asset library.
#     mie_nodes.py imports them at module level, so without this package the
#     engine's own nodes do not load. It is the same package MieNodes uses;
#     the three authoring packages ship as one train with one version.
#
#   torchaudio - the audio paths need it. ComfyUI does not ship it.
comfyui-mie-craft>=0.1.4
torchaudio

# The web front end (webapp/), which ships with this plugin and runs on
# this interpreter - so the pages and the nodes share one set of packages
# and one asset library.
#
#   flask - the web app itself.
#   soundfile - uploaded audio has to become WAV before the asset library
#     will take it.
#   comfyui-mie-llm / comfyui-mie-prompt - the platform table and the
#     prompt assets the pages read.
#
# Pillow is not listed: ComfyUI ships it.
flask>=3.0
soundfile>=0.12
comfyui-mie-llm>=0.1.5
comfyui-mie-prompt>=0.1.5
